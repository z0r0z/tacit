# Attestations

One file per contribution, `<index>-<name>.md`, written and signed by the contributor, from [TEMPLATE.md](TEMPLATE.md).
Add yours by pull request, or post it publicly and send the link.

A receipt says the coordinator accepted a contribution; an attestation is the contributor's own statement of how it
was made. Names and handles in the transcript are self-declared; the signature on an attestation is what ties a
contribution to a person or key.
