\begin{abstract}
\noindent
Secret Sats brings private payments to Bitcoin itself: amounts, senders and receivers stay hidden in
ordinary Bitcoin transactions, with no sidechain and no federation holding the pool.
Each payment carries a zero-knowledge proof that the payer owns an unspent note and that value balances,
anyone's node checks it against Bitcoin data, and relayers post payments so paying from the pool leaves
no fee trail.
The pool carries bitcoin-backed tokens rather than raw sats, because today's Bitcoin cannot release pooled
coins without someone holding a key; the first is cBTC, backed by BTC locked on Bitcoin and an
over-collateralized escrow that is slashed if the lock is broken.
Sats move in and out by atomic swap with no custodian, and a BitVM peg or, once Bitcoin adopts one, a
covenant can back the same pool unchanged.
cBTC is live on mainnet, and shielding, private payment and exit run end to end on signet today.
\end{abstract}
