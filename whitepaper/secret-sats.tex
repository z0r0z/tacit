Secret Sats pays bitcoin privately on Bitcoin itself.
BTC locked on Bitcoin becomes cBTC in Tacit's confidential pool on Ethereum, which Bitcoin reaches only
through zero-knowledge proofs, never a multisig, and cBTC comes back to Bitcoin as an ordinary Tacit asset.
There it can enter a pool that nobody holds: each payment carries a small proof, made on the payer's own
device in seconds, that a note exists, is theirs and balances, while amounts, senders and receivers stay
hidden.
Every node reaches the same pool state by replaying Bitcoin blocks and checking each proof itself, so
Bitcoin alone decides what has been spent.
Sats move in and out by atomic swap, and the pool runs on signet today.
