# Stuck-TAC bounty submission materials

This directory contains an option-A design/prototype submission and supporting evidence. It does not modify Tacit's runtime bridge, deployed contracts, pool, proof system, or verifying key. The Bitcoin swap desk already exists upstream; this submission evaluates its suitability as a bounded stuck-TAC recovery path.

**Status:** prototype/design review only. Simulated-chain tests pass; live Signet end-to-end validation remains blocked pending maintainer-confirmed asset/pool mapping and funded test inventory.

Start with [the one-page entry](bounty-entry-draft.md), then see the [technical review](technical-review.md), [requirements checklist](bounty-requirements-checklist.md), [simulation evidence](upstream-sim-evidence.md), and [Signet runbook](signet-e2e-runbook.md).
