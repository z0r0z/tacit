      Reading the relay…

      Where things stand

      Advance the header relay

      Sends Bitcoin’s block headers to BitcoinLightRelay.advanceTip. The contract checks each header’s proof of work, so only real blocks are accepted. Up to 40 headers per transaction, each confirmed in your wallet.

        BatchBlocksStatus

        The proofs are more than 2,016 blocks behind the relay. One batch can’t span that gap, so the pool needs a checkpoint closer to the proven block first. Anyone can call advanceReflectionAncestry(): it walks the relay’s chain back up to 2,016 blocks a call.

        Submit a proof

        Tacit’s prover publishes each proof, then submits it itself. Any wallet can submit one that is still waiting: attestBitcoinStateProven takes any valid proof over the pool’s current state.

        Reading the latest proof…

        Each proof is an SP1 zero-knowledge proof over one batch of Bitcoin blocks, paid for in PROVE credits on the Succinct network. A prover with a funded Succinct account makes it, not this page.

        Tacit’s prover looks for a new batch every 5 minutes. Anyone can run the same prover on the same public inputs with their own account: reflection-folder.js.
