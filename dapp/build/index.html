DeFi pool

Start here

Import the pool module and you have balances, every op and the relay client. No build step, framework or backend.

import { makeConfidentialPoolUx } from './dapp/confidential-pool-ux.js';
import * as secp from '@noble/secp256k1';
import { keccak_256 as keccak256 } from '@noble/hashes/sha3';
import { sha256 } from '@noble/hashes/sha256';

const tacit = makeConfidentialPoolUx({ secp, keccak256, sha256, network: 'mainnet' });
const acct  = tacit.account(walletPriv);    // the Ethereum account that sends deposits
const me    = tacit.identity(walletPriv);   // { priv, pubHex, owner, secret }
const { notes, byAsset } = await tacit.balance(walletPriv);

The key

The app derives one secp256k1 key from a fixed message the user signs once: identityMessage({ netName }) in identity-message.js, then prfBytesToScalar(sha256(signature)) with v folded to 27 or 28. The same wallet always gives the same key, so there is nothing to back up. tacit-address-kit.js does the derivation and the tacit1… address in one module with no dependencies.

The signature is the key

Whoever has it controls the user’s funds, and every Tacit app asks for the same text. Never send, log or store it, and zero it once the key is derived.

Before your first op

  • Balances are notes. Each holds an asset and an amount behind a commitment. Spending one publishes a nullifier, so it cannot be spent twice. Every op except a deposit is one settle() with a proof.
  • Amounts are 8-decimal units, not wei. ETH, TAC, cBTC and cUSD scale by 1e10; an amount must divide exactly.
  • Everything comes back from the key. tacit.recover({ walletPriv }) finds notes, farm and loan positions from chain data. Save a loan’s secrets before you submit it: they exist nowhere else.
  • One key per process, and rescan before a spend so every input comes from the same scan.
  • A good first loop: shield, send to yourself, withdraw. That covers a deposit, a proof, a spend and an exit.

DeFi pool

Shield, send, withdraw

// Shield: a plain deposit, then one relayed proof once it is mined
const w = await tacit.wrap({ walletPriv, amountWei: 10n ** 16n, ticker: 'cETH' });   // tETH in the app
await tacit.submitWrapSettle({ built: w });

// Send: to yourself (split or merge), or to someone's tacit1… address
const fee = await tacit.quoteTransferFee(5_000_000n, 'cETH');
await tacit.transfer({ walletPriv, notes, recipientPubHex: me.pubHex, amount: 5_000_000n, fee });
await tacit.stealthSend({ walletPriv, notes, recipientPubHex, amount: 5_000_000n });

// Withdraw
await tacit.unwrap({ note: notes[0], walletPriv, recipient: '0x…' });
  • Keep the wrap index. If the proof step fails, buildWrap with the same index rebuilds the same deposit. A deposit never expires; wrapping again would deposit twice.
  • Paying someone locks to a one-time key from their tacit1… address, and they claim it. The sender can refund after about 90 days. A .wei or .eth name can carry the address in its finance.tacit text record (confidential-names.js).
  • Withdrawing. unwrap pays a whole note out; sendUnwrap pays an exact amount and keeps the change private. The pool has no withdraw(): a plain call or transfer to it reverts. Confirm by the recipient’s balance.
  • Straight to Base or Robinhood Chain. ConfidentialRouter.exitAndExecute withdraws into the L2 bridge in one transaction (about 2,000,000 gas).

DeFi pool

Swap and earn

Each asset pair and fee tier is one pool with public reserves. A trade reaches them privately, as notes and a proof, or in public through TacitPublicAmm with no proof. Both move the same reserves, so liquidity is never split, and a swap’s fee stays in the reserves for the LPs.

const path = [{ assetNext: assetB, feeBps: 30 }];
const q = await tacit.quoteRoute({ asset0: assetA, amountIn, path });
await tacit.route({ walletPriv, inNote, amountIn, path, minOut });

// Earn: add liquidity and bond it to a farm in one settle
await tacit.lpBond({ walletPriv, controller: farm.manager, aNote, bNote, feeBps: 30, selfRelay: true });
const [pos] = await tacit.farmPositions({ walletPriv });
await tacit.farmHarvest({ walletPriv, position: pos });   // before unbonding
await tacit.farmUnbond({ walletPriv, position: pos });
  • Whole notes. A route spends its input note whole, up to four pools in one settle. Split with transfer first.
  • A private swap clears at the reserves it was proved against. If another trade lands first, it is refused, nothing is spent, and you quote again.
  • Finding a pool. There is no registry: compute tacit.routePoolId(a, b, feeBps) and read pools(poolId). The app checks the 30, 5, 100 and 1 bps tiers.
  • Founding a pool is sent from your own account (lpAdd with selfRelay: true), and sets the price.
  • Farms pay wTAC, which redeems one for one for TAC (farmRedeem). Read the live pools, weights and rate from GET /farm/program: they change, so don’t hardcode them. Harvest before you unbond; unbonding forfeits what was not harvested.
  • Aggregators use TacitPublicAmm.quoteSwap and swapPublic, or ConfidentialRouter’s permit and Permit2 entry points. Amounts must be multiples of 1e10.

DeFi pool

Bridge to Bitcoin and back

TAC, tETH, cBTC, cUSD and USDT cross the same way; only the asset id differs. No signer holds anything: each side proves the other’s state. A Bitcoin block counts once it is 24 blocks deep, about four hours, so say so in your interface.

Bitcoin to Ethereum

burn on Bitcoin→24 blocks→mint on Ethereum
const b = await tacit.bridgeBurnToPool({ prims, note, notePriv, fee: 0n, dest: { owner },
  deriveDestBlinding: (nu) => deriveBridgeMintBlinding({ privkey: priv, nullifier: nu }),
  isSpendable: (u) => isPlainSats(u) });
// once the burn is 24 blocks deep
await tacit.bridgeMint.bridgeMint({ ...b.mintArgs, recovery });
  • A mint at fee 0 is relayed free, so a holder with no ETH can finish.
  • Check the note first: GET /reflection/note-witness?leaf= finds it if it can bridge.

Ethereum to Bitcoin

burn on Ethereum→block covered→mint on Bitcoin
const r = await tacit.crossOut({ walletPriv, notes, amount, destOwner, destChain: 1 });
await broadcast.completeCrossOutOnBitcoin({ ...r, ...r.crossOuts[0] });   // crossout-broadcast.js
A wrong Bitcoin mint fails silently
  • The notes must sum to exactly amount + fee; destOwner is the recipient’s x-only Taproot key.
  • Broadcast only after GET /reflection/eth-state/covers says the burn’s block is covered, built from the claim id the pool emitted. completeCrossOutOnBitcoin does both checks.
  • Output 0 must pay destOwner as P2TR. GET /crossout/minted confirms the credit.

The fast lane

A Bitcoin note bound to this pool can be spent on Ethereum directly, with no burn and mint: tacit.fastlaneExit. The spend is recorded, so the note cannot also be spent on Bitcoin. buildTacMigration binds a note in one Bitcoin transaction.

DeFi pool

Borrow without selling

cBTC and cUSD, against Bitcoin

  1. Lock BTC in a self-custody output carrying the lock envelope (cbtc-lock.js). Pick the funding input first: the note’s blinding derives from it.
  2. Escrow wstETH worth 1.5 times the lock through CbtcEscrowHelper.postEscrowWithETH(outpoint).
  3. Mint cBTC once the lock is 24 blocks deep: tacit.mintCbtc({ walletPriv, outpoint, vBtc, blinding }), relayed and free.
  4. Borrow cUSD with tacit.defiActions(walletPriv).openCdp: 150% collateral to mint, liquidation below 130%. Mint at fee 0, and save the position’s secrets first.

TACD and TACE, against TAC

Two vaults take TAC as collateral: one lends TACD, a dollar, the other TACE, an ether. TacVaultRouter moves TAC in with a permit and borrows in one transaction. Read a vault with totalDebt(), debtCeiling() and vaults(owner). The app is tacit.finance/vault.

Pay pool

Private payments, proved on device

A smaller pool with one fixed circuit, for holding and paying privately. One transaction can shield, pay someone with change, withdraw and pay a relayer. The user’s device makes every proof, so nothing private leaves it. Its trusted setup closed after 176 public contributions. It runs tacit.finance/pay and the front page’s “Pay anyone”.

  • Drop-in wallet. https://tacit.finance/evm-pool/tacit-evm-pool-wallet.js is the whole wallet as one ES module with no imports: keys, scanning, proving and sending. It is served with Access-Control-Allow-Origin: * and checks the proving files against pinned hashes.
  • Same addresses on every chain: pool 0x000000c2A20657CE25f2Ba99737933D031AFBEE9, router 0x0000006C96Afa6f1cD4DF8FE19bc0d8B6A6Cd7B5, token zap 0x0000008EbBF2323f95c4fBc18254f3D65C53998c.
  • Fast first load. An on-chain checkpoint registry lets a new wallet start from a recent tree instead of the deploy block, then read older history in the background.
  • Relayers send a withdraw for a fee in the pool’s own asset, so a user never needs gas.

EVM-POOL.md has the token pools, keepers, deposit addresses and payment links.

Everything else

Proving and the API

Every DeFi-pool op except a deposit needs a proof. You choose who makes it and who sends it:

  1. Hosted, the default. The relay proves and sends settle(), paid from the op.
  2. Proof only. selfRelay: true on an SDK call takes the proof and sends settle() from your account.
  3. Your own prover. self-prover.js with your own Succinct account; the witness never reaches the relay.

Anyone with a GPU can prove for others and earn TAC at tacit.finance/prove. A wallet with no ETH can pay gas in TAC: it signs one order and TacitGasRelay runs it (gas-relay.js).

What the relay sees: the op you hand it, never your key or a note’s blinding. It can prove that op or decline it; it cannot redirect an output or raise the fee.

EndpointWhat it does
POST /confidential/submit{ type, op, memos, mode? } → { jobId }
GET /confidential/status?id=pending → proving → settled or failed
GET /confidential/quote?asset=The relay fee floor; quote with tacit.quoteOpFee

Submits are rate-limited per IP. Ops with no fee (a deposit’s proof, a cBTC mint, a zero-fee bridge mint) share a free daily budget; past it, add a fee.

List TAC

For a DEX, aggregator, lending market, wallet or market-data site. TAC was etched once on Bitcoin, 21,000,000 with no mint authority. On Ethereum it is an ERC-20 at 0xA1313eb9f3A445606D9583bcAc3ebeB56a858279 that only the pool can mint, and only against TAC from Bitcoin. Verify TAC checks all of it in your browser.

Verify it yourselfnothing hosted is trusted

A proof verifies against the pool’s immutable program key or the settle reverts, so nothing Tacit hosts decides what is valid. The pool has no proxy, upgrade, pause or key over funds. You can prove with your own account, rebuild the index from the pool’s logs, and replay the Bitcoin fold from public blocks. To check TAC’s fixed supply with nothing installed:
