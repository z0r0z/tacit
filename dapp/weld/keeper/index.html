Community ops

Bitcoin's state reaches Ethereum in two steps: a header relay that stores Bitcoin's block headers, and proofs that fold each batch of blocks into the pool. Both are plain on-chain calls that need no permission, the same calls Tacit's own services make. When either is behind, you can move it yourself from your own wallet and pay only the gas.

Where things stand

Advance the header relay

Sends Bitcoin block headers, read from a public explorer, to BitcoinLightRelay.advanceTip on Ethereum. The contract checks each header's proof of work itself, so only real Bitcoin blocks are accepted. Each transaction carries up to 40 headers, and your wallet asks you to confirm each one.

    BatchBlocksStatus

    The proofs are more than 2,016 blocks behind the relay. A proof can't span that gap in one batch, so the pool first needs a checkpoint closer to the proven block. advanceReflectionAncestry() sets it by walking the relay's chain back, up to 2,016 blocks a call; anyone can call it.

    Submit a proof

    Tacit's prover publishes each proof the moment it has one, then submits it itself. A proof waiting here can be submitted by any wallet: attestBitcoinStateProven needs no permission, only a valid proof over the pool's current state.

    Reading the latest proof…

    Each proof is an SP1 zero-knowledge proof over one batch of Bitcoin blocks, paid for in PROVE credits on the Succinct network, so it is made on a prover with a funded Succinct account rather than in this page.

    Tacit's prover looks for a new batch every 5 minutes. Anyone can run the same prover against the same public inputs with their own account: see reflection-folder.js.
