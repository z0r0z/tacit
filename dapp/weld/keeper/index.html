Community ops

Two permissionless calls keep Bitcoin’s state current on Ethereum: the header relay and the proofs. When one is behind, move it from your own wallet and pay only the network fee.

Where things stand

Advance the header relay

Sends Bitcoin’s block headers to BitcoinLightRelay.advanceTip. The contract checks each header’s proof of work, so only real blocks are accepted. Up to 40 headers per transaction, each confirmed in your wallet.

    BatchBlocksStatus

    The proofs are more than 2,016 blocks behind the relay. One batch can’t span that gap, so the pool needs a checkpoint closer to the proven block first. Anyone can call advanceReflectionAncestry(): it walks the relay’s chain back up to 2,016 blocks a call.

    Submit a proof

    Tacit’s prover publishes each proof, then submits it itself. Any wallet can submit one that is still waiting: attestBitcoinStateProven takes any valid proof over the pool’s current state.

    Reading the latest proof…

    Each proof is an SP1 zero-knowledge proof over one batch of Bitcoin blocks, paid for in PROVE credits on the Succinct network. A prover with a funded Succinct account makes it, not this page.

    Tacit’s prover looks for a new batch every 5 minutes. Anyone can run the same prover on the same public inputs with their own account: reflection-folder.js.

    Send a waiting settle

    Each proof on the open board pays its fee to the wallet that sends it.

    Run it on your machine

    One key advances the relay, lands published proofs and sends the board’s settles for their fees.

    git clone https://github.com/src-company/tacit
cd tacit && npm ci --omit=dev
RUNNER_KEY=0x… node tools/community-runner.mjs

    Modes and costs · Prove on your own device

    Prove wraps for points

    Your computer proves wraps people keep ready. Each proof the pool accepts earns TAC points to your address.

    curl -fsSL https://tacit.finance/prove.sh | sh -s -- 0xYourAddress

    Paste it in Terminal. It needs an Apple-silicon Mac or x86-64 Linux; the first proof downloads 6.2 GB and each takes about 5 to 10 minutes.

    Check on it or stop it 
    curl -fsSL https://tacit.finance/prove.sh | sh -s -- --status
curl -fsSL https://tacit.finance/prove.sh | sh -s -- --uninstall

    Prove for TAC

    Holders who want a proof fast sign a fee in TAC. Your computer claims the order, proves it, and is paid from their permit the moment the pool accepts it.

    curl -fsSL https://tacit.finance/prove.sh | sh   # installs tacit-prover and keeps it running (127.0.0.1)
git clone https://github.com/src-company/tacit
cd tacit && npm ci --omit=dev
RUNNER_KEY=0x… node tools/community-runner.mjs prove

    The key needs a little ETH for gas. Nothing moves unless the pool takes your proof. What it costs and earns · Market contract
