    How it works

    The pool carries bitcoin-backed cBTC. Sats become cBTC by atomic swap, cBTC is shielded into the pool, paid privately inside it, and leaves the same way.

    What’s hidden, what you trust

    Hidden

    • Amounts inside the pool
    • Who paid whom
    • Which note was spent
    • The payer’s Bitcoin wallet: relayers post the spend

    Visible

    • That a pool transaction happened, and when
    • The shield input and the exit output
    • Their amounts, when the note’s opening is public (a bought lot, say)

    You trust

    • Bitcoin
    • SP1 and its Groth16 key, the one already securing Tacit’s mainnet verifier
    • The indexer you choose, or your own
    • cBTC’s backing: locked BTC plus a slashable escrow

    Questions

    Is this a sidechain?

    No. Every payment is an ordinary Bitcoin transaction, and indexers check it.

    Where are my sats?

    Inside the pool you hold cBTC, backed by locked BTC and a slashable escrow. Sats move in and out by atomic swap.

    What if Tacit disappears?

    Run the open-source indexer. The hosted one is optional.

    Is there a trusted setup?

    It uses the same SP1 Groth16 key that already secures Tacit’s mainnet verifier. There is no new ceremony.

    Why Ethereum?

    cBTC’s escrow and pool live there today. The Bitcoin pool itself has no Ethereum dependency, and a BitVM or covenant peg can back it.
